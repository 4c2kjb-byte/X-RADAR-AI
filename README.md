# X-RADAR-AI

> أنت تتصفح الـFor You، وهو يفكر فيه معك.

X-RADAR-AI هو مساعد ذكاء اصطناعي شخصي يحلل المنشورات التي تظهر للمستخدم في صفحة **For You** على X.

## الفكرة

يقوم النظام بجمع المنشورات التي تظهر في For You، وتخزينها، ثم إرسالها إلى الذكاء الاصطناعي لتحليلها.

يمكن للمستخدم أن يسأل:

- وش أكثر شيء كان يدور اليوم؟
- ركز على AI
- هات أفضل 5
- وش الشيء الغريب؟
- وش صار اليوم؟
- قارن اليوم بأمس
- عطني المنشورات الأصلية
